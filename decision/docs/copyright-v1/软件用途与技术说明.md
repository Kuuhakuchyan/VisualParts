# 软件用途与技术说明

## 基本信息

| 项目 | 内容 |
|---|---|
| 软件名称 | 微境探界城市微气候监测与空间决策支持系统（拟定） |
| 软件版本 | V1.0，代码版本 1.0.0 |
| 软件类型 | 面向浏览器的气象监测与空间决策应用 |
| 使用对象 | 区域环境研究、气象观测与空间方案分析人员 |
| 客户端 | 支持 WebGL 的现代桌面/移动浏览器，按实际验收记录说明兼容范围 |
| 服务端 | Python 3.12、FastAPI；状态与场景使用 SQLite，固定传感器平台使用 PostgreSQL/MQTT 链路 |

## 用途

软件面向校园、街区和园区，将天气边界、逐小时预报、空间形态、热场情景与采集任务组织到统一工作区。用户可查看区域热风险，按人员类型、活动和暴露时间开展防护研判，在三维沙盘中比较建筑拆建方案，并规划移动采集任务和保存分析结果。

软件可使用 LCZ 分类和模拟数据演示空间差异及干预流程。模拟样例与真实观测使用来源字段区分，真实设备数据可以通过接口替换，不要求向外公开原始数据。环境热风险与防护建议用于辅助分析。

## 已实现功能

1. **门户与工作区导航。** 项目介绍、团队、项目记录与功能入口；决策大屏和操作子工作台分别承担展示和编辑。
2. **天气与时间序列。** 接入公开天气和逐小时预报，展示气温、湿度、风、辐射等环境条件，支持按时刻分析。
3. **空间热场。** 加载校园或街区的边界、路网、建筑和 LCZ 分类，构建带来源与版本的模拟格点热场，支持指标和图层切换。
4. **建筑方案推演。** 创建建筑体块、选择拆除对象、校验尺寸与范围，计算太阳位置、遮阴与热暴露指标，比较前后结果并保存场景。
5. **区域人群研判。** 选定区域，配置人群、活动和暴露时间，组织环境风险、建议与依据；危险症状按规则单独处理。
6. **AI 计算协作。** 将结构化环境数据和约束传入 AI 工具流程，生成候选参数或建议，调用本地计算并结合检索条款解释方案。无模型服务时保留规则与本地计算路径。
7. **传感器与移动观测。** 项目版设备树区分固定设备、UGV 和 UAV，支持状态、位置、温湿度、图像、历史记录及导出。移动遥测写入需要服务端凭据，公共展示投影不返回内部属性。
8. **采集任务仿真。** 在道路连通、障碍、可用能耗和返程限制下生成路线，展示采样覆盖与模拟观测。
9. **方案与结果。** 保存、读取和删除个人浏览器工作区的方案/场景，导出或回读相关报告、引用和结果哈希。不同接口的保存边界以接口文档为准，并非所有报告都在服务端长期保存。
10. **版本隔离。** AIC 版使用匿名化展示入口和独立配置，真实 UGV/UAV 接入与读取只提供给项目版。

## 技术结构

客户端由 Vite 构建，使用原生 JavaScript/TypeScript 组织工作区和交互；MapLibre GL JS、Cesium 和 Three.js 承担空间渲染与场景展示，ECharts 用于图表。主页模板与设备管理页由独立 API 服务提供。

决策 API 使用 FastAPI 和 Pydantic 完成路由及输入校验。本地使用 Shapely、PyProj、pvlib、Ladybug Comfort 和 pythermalcomfort 处理几何、坐标、太阳位置与热暴露指标；轻量模型以 JSON 产物交付。DeepSeek 通过服务端接口参与编排与解释，不在浏览器放置模型密钥。

状态和数据来源在接口响应中区分，方案/场景使用工作区令牌隔离。遥测支持设备 ID、设备类型、采样时间、同步状态、位置、温湿度和图像等结构化字段，图片单独进行格式及完整性校验。

## 交付与数据边界

软件交付包含第一方源代码、必要公共空间数据、模拟配置、模型产物、第三方许可与部署说明。生产密钥、实测原始数据、设备私有属性和服务器状态库单独保管。

本版本的登记范围围绕软件功能，不将长期实测、疾病确诊、临床效果、真实无人机飞控或专用 DeepSeek 权重训练列为已实现功能。后续真实数据接入和算法验证可以在同一软件框架内持续扩展。
