# 微境探界 V1.0 软著准备材料

本目录是当前气象与空间决策软件的材料工作目录，内容依据实际模块整理。它与 `../manual_*` 历史湿地软件模板分开管理。

建议登记名称：**微境探界城市微气候监测与空间决策支持系统**。软件版本：**V1.0 / 1.0.0**。名称最终核定后应同步申请信息、说明书、界面截图和源代码页眉。

## 现有材料

| 文件 | 用途 |
|---|---|
| 软件用途与技术说明.md | 描述当前已实现软件的用途、模块和技术结构 |
| 用户操作手册.md | 按真实用户流程组织操作步骤，作为截图与正式手册基础 |
| 权属与出件清单.md | 分离团队软件、第三方组件、模拟样例和私有数据，核对申请事实 |

## 本批不包含

本目录暂不填写未经核实的著作权人、合作开发归属、开发完成日期或首次发表日期；不根据团队成员展示顺序推定法律权属。不把源代码中的第三方库归为团队原创。

最终源代码鉴别材料、截图和可提交 PDF 应在候选版完成回归并冻结后生成。当前文档是工程准备稿，不能仅凭文件名视为已经满足受理格式。

模拟数据可以支持功能演示和操作截图。原始实测、坐标轨迹、观测图片、密钥、生产数据库不放入公开申请演示包；接口用脱敏或模拟样例说明。
