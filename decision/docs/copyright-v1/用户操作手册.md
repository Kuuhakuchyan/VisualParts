# 用户操作手册

适用软件：微境探界城市微气候监测与空间决策支持系统 V1.0（拟定）。本手册按现有入口和操作链编排，正式出件前应以冻结版逐步回归并配套截图。

## 进入平台

访问项目网站 `https://weather.nogamenolife.cn/`，在主页菜单进入决策平台、监测与设备管理等模块。决策工作区入口为 `/decision/#screen`。手机端通过导航切换页面，避免同时展开多个操作面板。

AIC 展示版入口为 `https://aic.nogamenolife.cn/aic/home.html`。该版本使用匿名化内容，真实移动设备数据接口与项目版隔离。

## 查看天气与空间热场

1. 进入决策大屏，选择区域和当前天气/预报时刻。
2. 等待天气与空间资源加载后，查看气温、湿度、风和所选热指标。
3. 切换热力、LCZ、建筑或相关分析图层，选择格点查看详情。
4. 播放逐小时序列时，确认时刻和结果状态一起变化；停止播放后选择具体时刻开展后续分析。
5. 模拟热场应与公开天气或真实观测的来源标识分别阅读。时间切换后以当前有效快照为准。

## 编辑建筑与比较方案

1. 打开建筑方案工作区，进入建造或建筑选择模式。
2. 新增建筑时指定位置、尺寸、高度和方向；拆除时选择现有建筑并加入方案。
3. 确认改动列表，退出编辑模式后检查新增体块和拆除效果。
4. 发起重算，等待结果完成；对比改造前、改造后或差值图层。
5. 查看受影响格点、结果时刻与方案版本。保存方案后刷新并回读，确认内容一致。
6. 不再需要的方案在列表中删除；删除失败时先刷新列表确认状态，不连续创建相同方案替代。

## 区域人群分析

1. 选择分析区域和天气时刻，进入区域分析功能。
2. 指定人群类型、活动和暴露时间。多人群分析时分别核对各组配置。
3. 发起分析，查看风险等级、影响因素、防护建议与引用来源。
4. 导出或保存相关结果时，保留结果哈希、数据时刻、规则和知识库版本，便于与地图对应。

## 管理传感器与 UGV/UAV

1. 打开项目版 `/sensors`，在设备树选择固定传感器、UGV 或 UAV。
2. 查看设备标识、在线状态、采样时间、位置、温湿度及图像等信息。没有数据的字段显示 `—`。
3. 使用刷新或历史记录查看新数据；导出所选设备的观测记录。
4. 在监测页对应移动观测区域查看设备数据。项目版显示接口的可见字段与私有写入接口分开。

设备写入由采集端调用 `/api/weather/telemetry/ugv` 或 `/api/weather/telemetry/uav`，请求通过 `X-Telemetry-Token` 验证。字段和样例以 `docs/UGV-UAV项目版接入接口.md` 及服务端 Schema 为准。不要把生产令牌放进截图、网页或公开演示文件。

## 采集任务仿真

选择区域、设备类型和能量/返程约束后创建模拟采集任务。查看路线是否沿道路或避开障碍，并核对覆盖格点、闭合返程和可用能耗。仿真任务不等同于向真实车辆或无人机下发飞控指令。

## 方案、报告与异常处理

保存的工作区方案与浏览器令牌相关，清除浏览器数据或换设备后不保证自动恢复。需要长期保管时导出报告或方案，不将浏览器存储视为服务器备份。

数据请求失败时保留已完成结果，重新获取天气/时刻后再发起分析。重算尚未完成时不要把旧地图截图与新报告混用。上游天气或 AI 服务异常时，以页面明确标识的状态及规则降级结果为准。

## 字段与结果核对

设备时间按北京时间显示，接口原始采样时间保留时区。气温单位为摄氏度、相对湿度为百分比；空间坐标和高度需按接入文档所列坐标系及高度基准理解。设备在线状态与采样值是否有效分别判断，不能只凭在线标识认定全部字段有效。

建筑场景中，新增数量与拟拆除数量分别记录。拟拆除改变的是当前方案，原建筑轮廓仍可在现状模式查看。撤销、重做和清空只操作当前情景；删除已保存场景需要确认，且不自动删除当前编辑副本。

差值页比较同一时刻、同位置的计算结果。平均辐射温度、UTCI、气温和遮阴分别使用各自图层与单位；UTCI变化不能直接加到气温上。切换指标后核对图例、时刻和报告版本，不以颜色深浅替代数值阅读。

多人群分析可在“分别设置人群活动与暴露”中为各组配置不同活动和时长；选中对应人群后查看其结果，不把某一组的暴露条件套给其他组。导出的完整报告包含各组输入，而不只包含当前展开的人群。

在设备页切换“观测记录”“定位轨迹”“视觉图像”查看各类数据。刷新失败时页面会保留上次记录并显示失败状态，用户应核对记录时间；恢复后再次刷新。设备搜索无匹配时调整搜索或状态筛选，不需要重新创建设备。

需要归档时导出场景和结果；读取保存情景后确认名称、拆建数量和图层，再发起所需重算。浏览器工作区凭证与导出的结果文件应分别保管；清除本地存储不等于撤回已下载的文件。

## 正式截图清单

主页、决策大屏、格点详情、逐小时序列、建筑新增与拆除、前后对比、人群分析、方案保存回读、设备树、UGV/UAV 模拟观测详情、采集路线和报告结果。全部截图应来自同一冻结版本，以模拟或脱敏数据生成。
