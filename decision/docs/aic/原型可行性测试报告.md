# 微境探界匿名热风险原型可行性测试报告

## 范围与结论

本报告记录软件原型测试，不是临床有效性验证或医师审核结论。独立匿名界面、来源快照、风险计算、症状即时提示、审核门禁、受约束DeepSeek接口、JSON/PDF报告已运行。医学知识库5条均待审核；生产医学建议不放行。历史空间残差预测未实现/未验证，不作为本届已完成结果。

## 测试环境

- 本地：Windows，Python 3.13.5，FastAPI 0.115.12、Pydantic 2.10.6、httpx 0.28.1；Vite 8构建。
- 服务器：Ubuntu，Python 3.12，现有127.0.0.1:3100决策服务，Nginx转发。
- 浏览器：Playwright控制Chromium，手机390×844、桌面1440×1000；另核查320及768宽度。
- 正式匿名地址：`https://weather.nogamenolife.cn/decision/aic/`。
- 可复现命令：在decision目录执行 `python -m unittest backend.aic.test_aic -v`、`npm run build`；工具命令见README。

## 样本与实际结果

自动化33项测试全部通过。样本为明确标记的合成测试夹具，覆盖NWS 90°F/70%参考计算105.9220206°F、连续分级阈值、低温不输出高温分级、过期/未来/缺失/单位错误/模拟来源拦截、阴凉与日晒只改变适用性说明，以及全部5个红旗枚举的升级。

检索测试验证未审核条款不公开、来源或中文文本变化使批准失效、适用条件过滤、冲突阻断、空检索。模型测试验证不配置/超时降级、未知或重复引用ID和自由医学文本拒绝。API测试验证姓名等额外字段拒绝、未知症状/无效时长拒绝、无气象时红旗跳过模型、报告可回算及哈希一致、原始快照回读、上游故障返回503，以及审核后的受约束AI路径只能输出原条款。测试中的虚拟审核仅存在于隔离临时文件，未写入生产。

真实天气：2024-06-12历史再分析网格在返回坐标约34.763°N、113.582°E，当日最高温小时为北京时间15:00，气温40.3°C、相对湿度19%；NWS热指数参考约39.5°C，归入危险。网页标明历史日期和网格来源，不视为现场实测。当前天气另取实时接口，值随时间变化。

真实DeepSeek：服务器使用独立私密配置完成deepseek-chat非医学接口测试，返回提供的测试ID，模式为ai_evidence_selection。此结果只证明接口可用及格式约束，不证明医学检索质量或临床效果。生产因知识与协议未审核仍禁用AI医学建议。

浏览器：匿名页读取真实来源、当前/历史切换、风险结果、红旗即时显示均通过；手机390宽度下页面scrollWidth为390，桌面1440宽度下为1440。学校、指导教师及校徽未出现在匿名入口，未加载原主页或三维页面。公开页浏览器控制台记录0错误、0警告。打印生成两页A4 PDF，已提取文字并渲染检查，包含气象输入、时间、规则版本及来源摘要。

- `decision/output/aic/api-cases.json`：自动化测试输入输出与引用结果，明确合成性质。
- `decision/output/aic/sources/`：4个权威来源原始HTML、文本和sources.json，5条节选均在快照中查得。

这些运行产物默认不进入Git；重现时可按工具重新生成。原文与审核版本变化必须重新核验，不能复用失效批准。
